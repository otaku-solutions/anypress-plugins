Your first site from the API, step by step.

Create a WordPress site for one of your customers from your own code.

Steps

  1. Ask us for API access from the contact page. You'll get a key and a secret.
  2. Create a site with one call to /v1/tenants, giving it a name and your customer's email address.
  3. Wait for the tenant.ready webhook, or check the site's status.
  4. Send your customer their sign-in link. They open WordPress with one click.

Where to read more

The API reference, the TypeScript and PHP SDKs and example code are in the public API repository, linked from the developers page.
