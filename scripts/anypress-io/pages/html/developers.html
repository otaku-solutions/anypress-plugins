  • REST API

    /v1/tenants

    Create, suspend, resume, restore, back up and delete sites. Every change runs in the background and reports its status.

  • Webhooks

    tenant.ready

    Signed events when a site is ready, fails, changes domain, gets backed up or is restored. No polling.

  • TypeScript & PHP SDKs

    npm · composer

    Typed clients built from the OpenAPI files, so your editor knows every call and field.

  • MCP connector

    /mcp

    Let Claude, ChatGPT or any MCP client create and manage sites, with a simple sign-in and per-area permissions.

  • Your own domains

    domains

    Add, remove and switch a site's domains, and give it its own email sending domain, all through the API.

  • n8n, Make and Zapier apps

    /automate

    Create sites from a form, a payment or a CRM step with the AnyPress app for n8n, Make or Zapier: pick a step, no code to write.

  • Open source

    GPL-3.0

    The API, the WordPress plugins and the dashboard are public under the GPL. Read it, improve it, or run it yourself with one installer.

Three calls to a live site.

  1. 1 Create the site, with your own id for it.
  2. 2Get tenant.ready with its address.
  3. 3 Send your customer to their new site, with the WordPress login you created for them.
signup.ts
await anypress.tenants.create({
  name: "Kettle & Crumb",
  externalId: customer.id,
  wordPressUserEmail: customer.email,
});

// later, in your webhook handler
if (event.type === "tenant.ready") {
  notify(customer, event.data.tenant.domainName);
}
