REST API

/v1/tenants

Create, suspend, resume, restore, back up and delete sites. Every change runs in the background and reports its status.

Webhooks

tenant.ready

Signed events when a site is ready, fails, changes domain, gets backed up or is restored. No polling.

Three calls to a live site.

  1. Create the site, with your own id for it.
  2. Get tenant.ready with its address.
  3. Send your customer to their new site, with the WordPress login you created for them.

signup.ts

await anypress.tenants.create({
  name: "Kettle & Crumb",
  externalId: customer.id,
  wordPressUserEmail: customer.email,
});

// later, in your webhook handler
if (event.type === "tenant.ready") {
  notify(customer, event.data.tenant.domainName);
}
